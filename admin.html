🎬 For large videos (>25MB) — use Google Drive:
1. Upload video to Google Drive → Share → Anyone with link → Viewer
2. Create a .txt file containing only the Drive share URL
3. Upload the .txt file to your GitHub gallery folder
4. Add the .txt filename to your folder's index.json
Example: index.json → ["photo1.jpg", "parade.txt", "photo2.jpg"]
Inside parade.txt → https://drive.google.com/file/d/YOUR_FILE_ID/view
